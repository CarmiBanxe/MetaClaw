# Гейт полной цепи: сделать «ноль из 324» замером, а не прозой

## Цель

Число полных цепей обязано **вычисляться механизмом**, а не повторяться мною в отчётах.
Сегодня «полных цепей ноль из 324» есть **утверждение центрального терминала**, ничем не
проверяемое, — то самое, за что я третий день ловлю чужие меры.

## Контекст: что измеряется сегодня и что нет

`scripts/function-coverage-gate.py` печатает `FUNCTION_COVERAGE=39/324` и **меряет одно звено из
десяти** — кодовый носитель. Цепь миссии, принятая аудитом, длиннее:

```
источник → обязательство → функция → роль/агент/инструкция → отдел/начальник →
департамент/руководитель/двойник → Director либо независимая ветвь → кодовый носитель →
тест/контроль → процесс → evidence
```

**Замер живьём (`d09125df`, `governance/org/accepted-org-manifest.json` +
`governance/org/function-coverage.json`):**

| звено | значение |
|---|---|
| функция объявлена | **324 / 324** |
| владелец функции назван | **312 / 324** (12 без владельца) |
| роль назначена человеку | **0 из 73** — все `UNAPPOINTED` |
| голова отдела ратифицирована | **0 из 38** — 12 `CANDIDATE_UNRATIFIED`, 26 `ABSENT_WITH_TASK` |
| кодовый носитель | **39 / 324** |
| проба у носителя | **39 / 39** |

**Отсюда вывод, меняющий представление о миссии.** Цепь разорвана на звеньях 4 и 5 **у всех 324
функций разом**, и разорвана не постройкой: назначение человека и ратификация головы суть акты
оператора (ADR-145). **Даже если бы все 324 носителя были построены и весь карантин паритета
выпущен, полных цепей осталось бы ноль.**

## Замер построимости: три звена из десяти не соединяются с функцией ВОВСЕ

Проверено прямым поиском идентификатора функции (`FN-[A-Z]{2,3}-\d+`) по источникам каждого звена,
`d09125df`:

| звено | источник в дереве | упоминаний функции |
|---|---|---|
| 1. источник | 103 файла `SOURCE-ATTESTATION.md` | **1 из 103** |
| 2. обязательство | `governance/regulatory-threshold-homes.json` | **0** |
| 10. процесс / evidence | `governance/security/e2e-scenarios.json` | **0** |

**Гейт цепи сегодня построим на шести звеньях из десяти, и это не оценка, а замер.** Три звена
не имеют машинно-читаемой связи с функцией: не «связь слабая», а **её нет**.

**Отсюда — обязанность, а не оговорка.** Гейт печатает эти три как `НЕ ИССЛЕДОВАНО` с названной
причиной «в дереве нет источника, соединяющего звено с функцией». Печатать их как `ОТСУТСТВУЕТ`
значило бы объявить дефектом постройки то, что есть **немота прибора**: отсутствие ответа у
измерителя не есть отсутствие предмета в мире. Печатать как `ЗАМКНУТО` — тем более.

**И отсюда же следующая единица работы, названная точно:** чтобы цепь стала измеримой, записи
аттестации источника, реестра обязательств и сквозных сценариев обязаны нести идентификатор
функции. Пока его нет, полнота цепи непроверяема по построению у трёх звеньев из десяти — и это
надо говорить прямо, а не прятать за общим числом.

## Область работ

### Входит
Гейт, вычисляющий состояние КАЖДОГО звена для КАЖДОЙ функции из машинно-читаемых источников;
трёхсостоятельный учёт; печать знаменателя и причины разрыва поимённо; отрицательные пробы.

### Не входит
Назначение людей, ратификация голов, изменение манифеста ради поднятия числа. Гейт **считает**,
а не решает.

## Функциональные требования

- **C1. Звено имеет ТРИ состояния, а не два.** `ЗАМКНУТО` · `ОТСУТСТВУЕТ` ·
  `ЗАКРЕПЛЕНО ЗА ОПЕРАТОРОМ`. Третье — не разновидность первого и не разновидность второго:
  звено, ждущее акта оператора, **не есть дефект постройки** и **не есть замкнутое звено**.
  Слить третье с первым значило бы объявить цепь целой; слить со вторым — вменить Фабрике то,
  чего она не вправе сделать.
- **C2. Требование, невыполнимое по построению, обязано быть названо, а не предъявлено.** Если в
  песочнице звено не может быть замкнуто **ни при каком поведении Фабрики**, гейт печатает это
  словами. Прежде я записала в контракт канала проверку, достижимую лишь ослаблением схемы, —
  повторять нельзя.
- **C3. Знаменатель приходит из карты.** 324 берутся из принятого манифеста, а не из сборки,
  которая их же назначила.
- **C4. Разрыв называется поимённо.** «Цепь разорвана» без указания звена и функции есть
  тот же общий «неуспех», против которого писан контракт полномочий.
- **C5. Число не растёт от переименований.** Звено засчитывается по разрешающемуся адресу и
  проверяемому состоянию, не по имени файла и не по совпадению строк.
- **C6. Понижение разрешено с названной причиной, повышение — только с доказательством.**
  Храповик, не умеющий опускаться при обнаруженном завышении, закрепляет ошибку вместо прогресса.

## Крайние случаи

- **E1.** Функция без владельца (12 таких) — `ОТСУТСТВУЕТ` на звене 5, не `ЗАКРЕПЛЕНО`.
- **E2.** Носитель объявлен, пробы нет — звено 8 замкнуто, звено 9 `ОТСУТСТВУЕТ`; половина
  функции, объявленная целой, вреднее незаявленности.
- **E3.** Звено, для которого в дереве нет машинно-читаемого источника вовсе, — `НЕ ИССЛЕДОВАНО`,
  и это четвёртое состояние печатается отдельно: отсутствие ответа у прибора не есть отсутствие
  предмета в мире.

## Критерии приёмки

- **G1.** Гейт печатает состояние всех десяти звеньев по каждой функции и итог полных цепей.
- **G2.** Итог сегодня равен **нулю**, и рядом напечатана причина: звенья 4 и 5 у всех функций.
- **G3.** Подстановка одной ратифицированной головы и одной назначенной роли **сдвигает** замер —
  мера жива, а не константа.
- **G4.** Объявление носителя без разрешающегося пути роняет гейт.
- **G5.** Слияние состояния `ЗАКРЕПЛЕНО ЗА ОПЕРАТОРОМ` с `ЗАМКНУТО` роняет отрицательную пробу.
- **G6.** Пустое дерево даёт не «ноль нарушений», а ноль замкнутых звеньев: **основание под
  вердиктом обязано двигаться**, даже когда вердикт неподвижен.

## Проверка

Каждый `C*` и `G*` — отдельно, с SHA, командой и наблюдаемым поведением. Канарейка обязательна
там, где утверждается принуждение, и обязана менять **значение**, а не достижимость: снятие ветви
ломает сужение типов и роняет замер вместе со сборкой.

## Определение готовности

PASS по каждому `C*` и `G*`; полный локальный набор гейтов; CI зелёный на точном SHA.
Любой FAIL, PARTIAL или BLOCKED — **NOT CLEAN**.

**Гейт не закрывает ни одной функции.** Он лишь перестаёт позволять мне утверждать число словами.
