# Девять непортированных доноров — разбор по родам, и «девять исполнимых» не выходит

**Замер:** 2026-09-11, дерево `4aaacb45` плюс чтение доноров в `banxe-architecture` и `imports/`.
**Повод:** корзина `DONOR_CARRIER_NOT_PORTED` объявляет предмет исполнимым, и её довод прямой:

> «Отличие от `DOMAIN_SPEC_ABSENT` в том, что **спецификацией служит само работающее поведение
> донора**: оно читается, и потому реализация здесь не была бы догадкой.»

Я собирался назвать эти девять «исполнимой работой» рядом с двенадцатью `CARRIER_INCOMPLETE` и
получить двадцать один. **Чтение доноров это опровергло.**

## Четыре рода вместо одного

| род | функций | донор | что это значит для работы |
|---|--:|---|---|
| **донор несёт поведение, лежит в дереве** | **2** | `imports/` | **исполнимо**: препятствие есть перенос |
| донор есть **голый протокол** | **3** | 55 строк, `Protocol` | **переносить нечего** — посылка корзины не держится |
| донор несёт поведение, но **подстановочное** | **3** | `InMemoryDeployPort` | перенос даёт **имитирующий** носитель |
| ссылка **ложна по пути**, донор найден | 1 | исправлено картой | исполнимо после правки адреса |

## Проверено адресно, а не по записи

**Два исполнимых:**

```
FN-AU-03  imports/fiat-int/banxe-2fa — 198 файлов, и служба кодов восстановления названа поимённо:
          src/2fa/services/2fa-recovery-code.service.ts
FN-FC-03  imports/vabs-int/core/providers/cp-provider — `processCheckKytTasks` найден в двух файлах
```

Карта попутно **исправила собственный адрес**: задача названа в S2 §1 как «crypto-int cron», а лежит
у `vabs-int`. Запись говорит об этом лучше меня: «основание, присвоенное по неверному адресу,
неверно дважды, и следующий читатель искал бы в доноре, где этого кода нет».

**Три протокола — `FN-SEC-11 · 12 · 13`:**

```
bank-rooms/F4-security-room/runtime/secrets/rotation_port.py — 55 строк
class SecretRotationPort(Protocol):
    def rotate(self, secret_id: str) -> RotationResult: ...
    def get_rotation_status(...) -> RotationStatus: ...
    def check_overdue(self) -> list[SecretMetadata]: ...
```

**Поведения нет ни строки.** Три структуры данных (`RotationResult`, `RotationStatus`,
`SecretMetadata`) перенести можно — **поведение нельзя, потому что его там нет**. Для этих трёх
довод корзины («спецификацией служит работающее поведение») **ложен по факту**, и разряд, вероятно,
иной. Смена разряда есть правка карты и идёт отдельно.

**Три подстановочных — `FN-PL-12 · 13 · 14`:** и это МОЯ добавка к записи.

Запись карты проверила ссылку **до строки** — «первый случай в реестре, где донорская ссылка
проверена именно так, а не признана на слово», — и это верно: 236 строк, названные `async def`
попадают точно. **Но о роде реализации запись не сказала.** Прочитал:

```
class DeployPort(abc.ABC):          # три абстрактных метода, тела — многоточия
class InMemoryDeployPort(DeployPort)  # ЕДИНСТВЕННАЯ конкретная реализация
```

**Перенести можно только `InMemoryDeployPort`** — то есть получить носитель, чьё поведение
имитировано. Ровно то, о чём предупреждает соседняя корзина: «носитель без канала есть заглушка, а
шов из заглушек доказывает работу заглушек».

## Вывод, и он уменьшает, а не увеличивает

**Исполнимой работы в этой корзине — два, а не девять** (три, если считать `FN-PL-16` после правки
адреса). Остальные шесть упираются либо в отсутствие поведения у донора, либо в его подстановочность.

**Итог по всей карте, честно:**

```
исполнимо сейчас, без решения и без внешнего канала:
   CARRIER_INCOMPLETE   12  (из них FN-LG-01 отпала по отдельному замеру — предмет шире записанного)
   DONOR ... портируемо   2–3
   MEASUREMENT_ABSENT     2  → прочитаны мной, оба оказались DOMAIN_SPEC_ABSENT по существу
```

**То есть порядка тринадцати-четырнадцати функций, а не двадцати одной.** Число уменьшилось от
чтения — и это его единственный честный источник.

## Четвёртый узкий образец за такт — снова мой

Считая тела-многоточия, искал `^\s*\.\.\.\s*$` и получил **ноль** при четырёх наличествующих:
в этом файле `...` стоит **в одну строку с подписью**. Вывод «тел нет» совпал бы с истиной по
случайности и по неверной причине.

> **Образец, написанный под воображаемую запись предмета, меряет воображение.**
> Сегодня это уже четвёртый случай: скобка в `sort`, довод вместо тела, `CLOSED` вместо `isActive`,
> и здесь.
