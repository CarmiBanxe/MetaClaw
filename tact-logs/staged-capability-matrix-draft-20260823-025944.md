## Kimi/Moonshot via FCC

- **Allowed:** sanitized document reading; research synthesis; task decomposition; ADR option drafts; documentation drafts.
- **Forbidden:** protected data; final material approval; production secrets; real KYC/KYB/AML/payment/ledger payloads.
- **Proof success:** Required sections present; no sensitive markers; route/model/evidence recorded.
- **Fallback:** Explicit recorded reroute to another Tier A allowlisted cloud route; never silently to local/cloud across data boundary.

## DeepSeek chat/coder via FCC
