## Твоё дерево — заведи его ПЕРВОЙ КОМАНДОЙ, до всякого чтения

```bash
# ИМЕНА ЛАТИНСКИЕ — ОБЯЗАТЕЛЬНО. bash кириллические не берёт: присваивание молча не
# происходит, переменная пуста, и `worktree add "$ДЕРЕВО"` заводит дерево по ЛИТЕРАЛЬНОМУ
# пути «$ДЕРЕВО» ВНУТРИ общего дерева. Случилось 2026-09-11 по вине этого самого файла.
branch=agent/factory/director01/<ИМЯ>
tree=/home/mmber/wt/<КОРОТКОЕ-ИМЯ>
git -C /home/mmber/wt/bt-sepa01 worktree add "$tree" -b "$branch" b87a9041
cd "$tree"
```

**Проще и надёжнее — без переменных вовсе.** Подставь значения руками:

```bash
git -C /home/mmber/wt/bt-sepa01 worktree add /home/mmber/wt/<КОРОТКОЕ-ИМЯ> \
    -b agent/factory/director01/<ИМЯ> b87a9041
cd /home/mmber/wt/<КОРОТКОЕ-ИМЯ>
```

**Проверь, что переселился, и не верь тому, что не проверил:**

```bash
git -C /home/mmber/wt/<КОРОТКОЕ-ИМЯ> rev-parse --abbrev-ref HEAD   # твоя ветка
git -C /home/mmber/wt/bt-sepa01      rev-parse --abbrev-ref HEAD   # sepa-outgoing-entry
ls -d '/home/mmber/wt/bt-sepa01/$tree' 2>/dev/null && echo "ДЕРЕВО ЗАВЕДЕНО ПО ЛИТЕРАЛЬНОМУ ИМЕНИ — снеси и заведи заново"
```

**Обязаны дать РАЗНЫЕ ветки.** Если совпали — ты в общем дереве, и любая твоя подсадка видна
чужому замеру как состояние дерева.

## ОТ ЧЕГО ЗАВОДИТЬ ДЕРЕВО — от вершины интеграции, а не от базы

**По умолчанию — от вершины ветви `agent/factory/director01/integration`,** а не от `b87a9041`.

**Зачем.** 2026-09-11 линия, заведённая от базы, честно нашла дефект
(`ALREADY_ENFORCED_DIFFERENTLY` объявлен и не выбрасывается) — **уже починенный в интеграции**:
на базе одно вхождение, в интеграции три, среди них сам выброс. **Ложную находку создал
диспетчер, а не исполнитель:** линия измерила ровно то дерево, которое ей дали.

**От базы — только когда изоляция от чужих правок важнее свежести**, и тогда это говорится в
задании вслух вместе с доводом. Молчаливый выбор базы есть решение, принятое не думая.

Узнать вершину: `git -C /home/mmber/wt/bt-sepa01 rev-parse --short agent/factory/director01/integration`

## Чего не делать — и почему именно

| запрет | довод |
|---|---|
| `cd /home/mmber/wt/bt-sepa01` и работа там | это **база чтения** центрального терминала и опора других линий |
| `git checkout <своя ветка>` в общем дереве | переключает общее дерево; `worktree add` не есть `checkout` |
| `push` куда бы то ни было | отправка есть решение оператора (ADR-145) |
| трогать `main` | то же основание |
| трогать чужие worktree и ветки | линии идут параллельно и друг о друге не знают |

## Дисциплина замера — не ослабляется ничем

- **Сначала аудит, потом действие.** Не чини того, чего не измерил.
- **Код возврата снимай без конвейера:** `cmd > файл 2>&1; echo $?`. `$?` после `| tail` есть код
  `tail`. Готовая оснастка: `tools/run-measure.sh <каталог> <команда...>`.
- **Число по образцу при счёте отсутствия есть ВЕРХНЯЯ ГРАНИЦА:** непопадание в образец имеет две
  причины — нет вовсе и есть под другим именем. Так и пиши.
- **Канарейка обязана РАЗЛИЧАТЬ,** а не просто краснеть: подсади порчу ровно того предмета, который
  мера называет, убедись, что покраснело **зависимое**, и верни **байтами** со сверкой
  `sha256sum` до и после.
- **Зелёное, полученное ослаблением, хуже красного.** Отказ честнее молчаливого прохода.
- **Ничего не удаляй и не «упрощай».** Показ дефекта, найденный по дороге, остаётся в дереве.
- **Вышло за предмет задания — не чини, назови поимённо** и оставь оператору.

## ЗАМЕР — СО СНИМКА, А НЕ ИЗ ОБЩЕГО ДЕРЕВА (добавлено 2026-09-11, R54)

Читающая линия, которой поручено **мерить**, а не менять, берёт предмет **снимком**:

```bash
git -C <дерево> archive <вершина> | tar -x -C <временный каталог>
```

и меряет **в нём**. Причина измерена, а не предположена: 2026-09-11 читающая линия мерила в общем
дереве `fx-integration`, где одновременно работала другая; вершина ушла на шесть коммитов, файл
выборки правили у неё под руками. Замер уцелел **по удаче, а не по устройству**.

**Отсюда же: не требуй от линии чистого `git status` в дереве, которое она делит с другой.**
Требование, невыполнимое по устройству обстановки, оставляет исполнителю два дурных выхода —
ослушаться молча либо отчитаться о чистоте, которой нет.

## ВЕРДИКТ МЕРЫ НАЗЫВАЕТСЯ ВМЕСТЕ СО СРЕДОЙ — И В ПОРУЧЕНИИ ТОЖЕ (добавлено 2026-09-12)

Свежий worktree **не несёт `dist`**. Три предела сценария `CLOUD_OUTAGE` ссылаются внутрь сборки,
и потому мера сквозных сценариев в свежем дереве **красна всегда**, а в собранном — зелена.
Замерено на одном коммите: `fx-integration` — 145 каталогов `dist`, `КОД=0`; свежее дерево — 0
каталогов, `КОД=1`.

**Отсюда два следствия.**

1. **Поручение, называющее ожидаемый вердикт, обязано называть среду.** «Семь мер зелены» без
   этого — неверно для всякой линии, работающей в своём дереве, и линия потратит такт, доказывая
   обратное. Правильно: «шесть зелены в свежем дереве; седьмая красна тремя `dist`-адресами —
   это известно, названо оператору и не твой предмет».
2. **Линия, увидевшая красное, которого не делала, обязана это сказать** — и сказать **числом**,
   а не отмахнуться. Одна из линий так и сделала, и поправила меня.

## МЕРЫ ПРОГОНЯЮТСЯ ВСЕ, А НЕ ПО СПИСКУ (добавлено 2026-09-12, после собственной ошибки)

В каталоге `scripts/` дерева **пятьдесят шесть** мер вида `*gate*.py`. Я всю ночь называла линиям
**семь** — и дважды оставила дерево краснее, чем взяла, не заметив этого.

**Замерено:** на вершине начала ночи `threshold-constant-gate` и `unfailable-refusal-probe-gate`
были **зелены**; к утру обе красны, и обе — от одной ветви:

```
✗ break-case-sla.ts:83  BREAK_CASE_SLA_MAX_HOURS = 720 — пороговая постоянная, в реестре не объявлена
✗ break-case-sla.spec.ts:124                          — проба отказа БЕЗЗАЩИТНА: упасть не может
```

Линия отчиталась честно по тем мерам, что я назвала. **Узок был список, а не её работа.**

**Отсюда:** строящая линия прогоняет **все** меры каталога и называет **красные поимённо** —
и те, что были красны до неё (**это надо показать снимком прежней вершины**), и те, что покраснели
от неё. Список из нескольких имён годится только для **ожидания**, не для **проверки**.

```bash
# все меры, одним обходом, с разделением «было красно / стало красно»
python3 - <<'ПРОГОН'
import pathlib, subprocess
for p in sorted(pathlib.Path("scripts").glob("*gate*.py")):
    r = subprocess.run(["python3", str(p)], capture_output=True, text=True, timeout=180)
    if r.returncode: print(p.name, "КРАСНА")
ПРОГОН
```
